# ✂ Ahlam Coiffure — Site Web Professionnel

## 📌 Description
Ahlam Coiffure est un site web professionnel complet dédié à la coiffure 
féminine africaine et moderne, développé avec PHP et MySQL.
Il permet aux clientes de découvrir les services du salon, consulter la 
galerie de réalisations, prendre rendez-vous en ligne et à l'administratrice 
de gérer tout le contenu depuis un espace sécurisé.

## 🌐 Pages du site
- **Accueil** — Présentation du salon et services en vedette
- **Services** — Liste complète avec prix et durée
- **Galerie** — Photos des réalisations du salon
- **Réservation** — Formulaire de prise de rendez-vous en ligne
- **Contact** — Coordonnées et formulaire de message
- **Espace Admin** — Tableau de bord sécurisé pour gérer les RDV, clients, services et galerie

## 🗄️ Base de données
- 5 tables MySQL : clients, services, rendez_vous, admin, galerie

## 🛠️ Technologies utilisées
- HTML5 / CSS3
- PHP 8
- MySQL
- XAMPP (serveur local)
- JavaScript
